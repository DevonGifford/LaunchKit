# Code of Conduct

LaunchKit is a shared foundation that several independent projects build on.
That only works if people can report problems, propose changes and disagree
about them without the conversation turning personal. This document sets the
expectations for everyone who participates in this repository and in any
downstream repository that adopts it.

## Our standards

Behaviour that keeps collaboration productive:

- Being respectful of differing viewpoints, experience levels and priorities.
- Giving and accepting constructive feedback about code and ideas, not people.
- Assuming good intent, and asking before concluding otherwise.
- Taking responsibility for mistakes and learning from them.
- Focusing on what is best for the projects that depend on LaunchKit.

Behaviour that is not acceptable:

- Harassment, insults, derogatory comments or personal or political attacks.
- Sexualized language or imagery, or unwelcome attention of any kind.
- Publishing someone else's private information without explicit permission.
- Sustained disruption of discussions, reviews or issue threads.
- Any other conduct that would reasonably be considered inappropriate in a
  professional setting.

## Scope

This code of conduct applies in all project spaces — issues, pull requests,
discussions, review comments and commit messages — and when someone is
representing the project in public spaces.

## Reporting

Report unacceptable behaviour privately to the maintainer,
[@DevonGifford](https://github.com/DevonGifford), using the contact details on
that GitHub profile. Please include links to the relevant threads and any
context that helps. Reports are handled confidentially, and the person who
reported is never identified to the subject of a report without their consent.

Security vulnerabilities are not conduct issues — see [SECURITY.md](SECURITY.md).

## Enforcement

The maintainer reviews every report and decides on a response proportionate to
what happened. In increasing order of severity:

1. **Correction** — a private, written explanation of what was inappropriate.
2. **Warning** — a formal warning with consequences for continued behaviour.
3. **Temporary ban** — no interaction with the project for a specified period.
4. **Permanent ban** — no further participation in the project.

Maintainers who do not follow or enforce this code of conduct in good faith may
face the same consequences.

## Downstream projects

Repositories derived from LaunchKit inherit this file. Each downstream project
should replace the reporting contact above with its own maintainers before
accepting outside contributions.
